# 3.1.23 — Chat tabs use sprite emoji icon, not the avatar PNG

## What it adds
Tobe: "i did a restart as you can see on the picture but the chat channels still have the robot icon" — after v3.1.22 was deployed. The v3.1.22 fix used `agent.emoji || getSpriteIcon(sprite) || '🤖'` in the chat tab rendering, but the code path that ran was the OTHER branch — the one that shows the avatar PNG. The agent has an `avatar` (a 32×32 PNG generated by the avatar editor), and that branch ran first, never reaching the emoji fallback.

The avatars are small pixel-art PNGs of the companion's sprite (boar for Clawsuu, hare for Lamasuu). They're not "robot icons" per se — they're correct sprite renders — but they don't read well at chat-tab size (32×32 stretched into ~24px), and they're not the consistent emoji icons Tobe asked for ("a related emoji icon for each sprite which are applied to the companion").

## Change: chat tabs use the emoji icon, not the avatar
`renderCompanionChannelTabs` in `app.js` no longer renders the avatar PNG in chat tabs. It always renders the emoji icon (`agent.emoji || getSpriteIcon(agent._pixelCompanionId) || '🤖'`). The avatar PNG is still rendered in:
- `updateFocused` (the inspect panel side row) — line 510
- `updateInspect` (the inspect panel header) — line 1410

…where the avatar is at the right scale (larger) and the user has explicitly opened the inspect panel to look at it.

## Files changed
- `src/js/app.js` — `renderCompanionChannelTabs` no longer renders the avatar PNG; always renders the emoji icon
- `package.json` — 3.1.22 → 3.1.23

## Lesson: when there are two visual representations of the same thing, pick one
The companion has both a sprite catalog icon (emoji) and a per-agent avatar (PNG). They were rendered in different places (chat tabs used avatar, inspect used avatar, chat messages used emoji). Tobe wants the emoji to be the visible identifier for the chat tab. Now they are: chat tabs show emoji, inspect panel shows avatar.

If you want the avatar back in chat tabs, restore the original branch — but the emoji is a more consistent and legible identifier at small sizes, especially when the user is on the mobile where they see the same emoji too.
